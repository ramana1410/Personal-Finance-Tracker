# 💰 Personal Finance Dashboard

A modern React-based web app to manage your personal finances — track transactions, set bill reminders, monitor debt, and calculate taxes.

![Demo Screenshot](/public/logo512.png) <!-- Replace later with real screenshot -->

## 🚀 Features

- 📊 **Dashboard**: Overview of income, expenses, and savings
- 💵 **Transaction Management**: Add, view, and categorize transactions
- 📅 **Bill Reminders**: Never miss a payment
- 🔁 **Debt Tracking**: Monitor loans and repayment progress
- 🧮 **Tax Calculator**: Estimate tax liability based on income
- 🌐 **Responsive Design**: Works on desktop and mobile

## 🛠️ Built With

- React.js
- JavaScript (ES6+)
- CSS
- Webpack (via Create React App)
